# DSP Measurements

Reproducible measurements of flagship kernels, generated by
`cargo run --release --example dsp_report -p sonido-effects`. Signals are
analysed with the in-repo `sonido-analysis` FFT/THD/RT60 tooling — no external
tools, no hand-tuned numbers.

Test conditions: 48000 Hz sample rate, 16384-point FFT, Blackman–Harris window.

## Distortion — harmonic structure (30 dB drive, 1 kHz)

Amplitude of each harmonic relative to the fundamental:

| Harmonic | Freq (Hz) | Level (dB) |
|---------:|----------:|-----------:|
|        1 |      1000 |        0.0 |
|        2 |      2000 |     -114.9 |
|        3 |      3000 |       -9.6 |
|        4 |      4000 |     -114.2 |
|        5 |      5000 |      -14.5 |
|        6 |      6000 |     -115.9 |
|        7 |      7000 |      -17.8 |
|        8 |      8000 |     -118.4 |

Kernels run at base rate here, as they do on every shipping path (plugin, CLI,
pedal) — none wraps kernels in `Oversampled<N>`. Aliasing of these harmonics is
held down in the kernel itself by first-order ADAA (antiderivative anti-aliasing)
waveshaping; `Oversampled<N>` (`crates/sonido-core/src/oversample.rs`) is an
opt-in wrapper, not part of any shipping signal path.
